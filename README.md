# N&C Benz Spectrum

A vibrant Mercedes-Benz car selling website built with React and Vite.

## Pages
- Home
- Vehicles
- Stock
- Contact

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:5174` in your browser.

## Features
- Purple-themed luxury design
- Slide hero section on the home page
- Mercedes-Benz vehicle collections and detail pages
- Stock filter for All, New, Demo, and Used cars
- Contact form and Nairobi Ngong Road map
- Quote/test-drive form with submission prompt
